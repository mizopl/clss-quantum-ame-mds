# Explicit Constructions and Purity Audit for Quantum AME States ($n \le 20$) and MDS Codes

This repository contains 21 machine-verified JSON certificates (`certificates/*.json`) and a standalone, zero-dependency Python 3 verification script (`verify_all_ame_submissions.py`) for new and repaired entries in:

- **Table of AME and $k$-Uniform States** ([tp.nt.uni-siegen.de/ame/table.html](https://tp.nt.uni-siegen.de/ame/table.html) / [huberfe.github.io/ame](https://huberfe.github.io/ame), maintained by F. Huber and N. Wyderka)
- **Bounds on the Minimum Distance of Linear and Quantum Codes** ([codetables.de](https://codetables.de), maintained by M. Grassl)

All constructions and structural theorems in this repository were generated by an experimental autonomous research loop (**CLSS — Closed-Loop Scientific Search**) running locally on a single consumer laptop (Apple M1 Pro) using standard, publicly available LLM subscriptions without additional API token budgets or cluster compute.

## Verification

Requires only standard Python 3 (no external libraries).

```bash
python3 verify_all_ame_submissions.py
```

The script checks the SHA-256 integrity of all 21 certificates, verifies symmetry and full rank across bipartite cuts over $\mathbb{F}_q$, verifies Hermitian unitarity $A A^\dagger = -I_k$ and minor nonsingularity over $\mathbb{F}_{q^2}$ together with the symplectic reduction $\Gamma_{2k} = X^{-1} Z \pmod q$, and writes the summary to `VERIFICATION_REPORT.json` in `~0.22` seconds.

## Summary of Results

### 1. Purity Audit of `[[15, 0, 8]]_5` and `[[15, 0, 8]]_7` & Explicit Pure Replacement for $\mathrm{AME}(15, 7)$

For a 1-dimensional stabilizer state ($K = q^0 = 1$), there are no nontrivial logical cosets, so the minimum distance coincides strictly with the pure distance ($d = d_{\mathrm{pure}}$). Any stabilizer element of weight $w < \lfloor n/2 \rfloor + 1$ induces a singular $\lfloor n/2 \rfloor$-party reduced density matrix.

- **`[[15, 0, 8]]_5` (impure):** A weight-distribution audit of the cyclic stabilizer code derived from the $[15, 7, 8]_5$ BCH code shows $d_{\mathrm{pure}} = 6 < 8$ ($276$ weight-6 and $2,940$ weight-7 stabilizer elements). Exhaustive backtracking over all $5^7 = 78,125$ symmetric circulant graph states over $\mathbb{F}_5$ shows that no circulant graph state achieves $\mathrm{AME}(15, 5)$ (minimum $630 / 6,435$ singular cuts). Thus $\mathrm{AME}(15, 5)$ remains open.
- **`[[15, 0, 8]]_7` (impure BCH replaced by pure circulant graph state):** The tabulated cyclic BCH stabilizer code has $d_{\mathrm{pure}} = 7 < 8$. We construct an explicit pure symmetric circulant graph state over $\mathbb{F}_7$ (`certificates/ame_15_7_pure_circulant_certificate.json`) with first row:
  $$r_0 = [0, 1, 1, 2, 1, 4, 6, 4, 4, 6, 4, 1, 2, 1, 1] \pmod 7$$
  All $\binom{15}{7} = 6,435$ bipartite $7 \times 8$ submatrices ($429$ cyclic orbits) have full rank $7$ over $\mathbb{F}_7$.

### 2. Pure Quantum MDS Code `[[13, 1, 7]]_5` (Improving `codetables.de` $d = 6 \to 7$)

By puncturing and deleting the $14 \times 14$ bordered Paley conference matrix $C_{14}$ at a single vertex over $\mathbb{F}_5$, we obtain an explicit pure `[[13, 1, 7]]_5` stabilizer code (`certificates/ame_13_5_quantum_mds_13_1_7_certificate.json`). Every one of the $\binom{13}{6} = 1,716$ 6-party cuts has full symplectic rank mod $5$, reaching the Quantum Singleton Bound $n - k + 2 = 2d$.

### 3. Quadratic-Extension Cayley Unitary Construction of $\mathrm{AME}(16, 11)$ and $\mathrm{AME}(16, 13)$

For $n = 16$, standard symmetric double-circulant graph states over $\mathbb{F}_q$ experience an algebraic phase transition at $q_c(16) \approx 15.10$ due to $\sigma$-invariant cut degeneracies. To construct $\mathrm{AME}(16, 11)$ and $\mathrm{AME}(16, 13)$, we parameterize $8 \times 8$ $\lambda$-constacyclic Hermitian unitary matrices over $\mathbb{F}_{q^2}$ via the Cayley transform:
$$A_8 = \mu (I_8 - S)(I_8 + S)^{-1}, \qquad S^\dagger = -S, \qquad \lambda^{q+1} = 1, \qquad \mu^{q+1} = -1.$$
Over $\mathbb{F}_{q^2}$, generic minor singularity rates drop from $1/q$ to $1/q^2$, and Jacobi's determinant identity for unitary matrices ($\det((A_k)_{I^c, J^c}) \ne 0 \iff \det((A_k)_{I, J}) \ne 0$) reduces MDS verification to minors of order $1 \le r \le 4$. Trace-symplectic reduction $\Gamma_{16} = X^{-1} Z \pmod q$ then yields explicit $16 \times 16$ symmetric graph states over $\mathbb{F}_{11}$ and $\mathbb{F}_{13}$ with $0 / 12,870$ singular 8-party cuts (`certificates/ame_16_11_pure_hermitian_constacyclic_graph_certificate.json` and `certificates/ame_16_13_pure_hermitian_constacyclic_graph_certificate.json`).

## Methodology: Closed-Loop Scientific Search (CLSS)

Instead of large-scale evolutionary token sampling, the discovery loop enforces strict token and compute efficiency through three mechanisms:

1. **Preregistered Falsifiable Bets & No-Go Extraction:** Every search ansatz is logged with a calibrated probability prior before execution. When an exhaustive or local search fails (e.g., bordered 15-circulants or standard $D_8$ double-circulants at $n = 16$ for small $q$), the loop inspects the invariant kernel of the failing cuts to prove a structural obstruction (such as the $n = 4m$ involution-parity no-go theorem, the Jacobi adjugate corank-2 trap $\operatorname{adj}(M) \equiv \mathbf{0}$ at $\operatorname{rank} \le k - 2$, and the exact reflection-subspace phase transition $q_c(19) \in (13, 16)$).
2. **Representation Shifting ($\mathbb{F}_q \to \mathbb{F}_{q^2} \to \mathbb{F}_q$):** Once a phase-transition threshold rules out a symmetry group over $\mathbb{F}_q$, the loop shifts to an algebraic cover with lower generic determinantal codimension (such as the Cayley $\lambda$-constacyclic unitary manifold over $\mathbb{F}_{q^2}$) and projects nonsingular solutions back to the base field.
3. **Independent Verification Gate:** Every candidate certificate is verified from scratch by an independent zero-dependency script prior to acceptance.
